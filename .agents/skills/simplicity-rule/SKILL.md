# Regla de Simplicidad y Cero Comandos Innecesarios

1. **No ejecutar comandos innecesarios**: No intentes ejecutar comandos de terminal, scripts de Python u operaciones externas si el problema se puede resolver directamente en los archivos de código del proyecto (CSS, HTML, Astro, JS).
2. **Solución más sencilla y práctica**: Busca siempre la manera más simple, limpia, directa y mantenible de resolver cualquier ajuste o requerimiento.
