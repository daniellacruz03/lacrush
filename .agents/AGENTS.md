# Reglas y Guías del Agente / Workspace Rules

- **Sin comandos innecesarios**: NO ejecutes comandos de terminal o scripts externos innecesarios (como scripts en Python o herramientas adicionales) si el problema puede ser resuelto directamente en el código del proyecto.
- **Soluciones más sencillas y prácticas**: Elige siempre la forma más simple, limpia y directa de resolver cualquier problema (por ejemplo, soluciones nativas en CSS/HTML/JS, modificaciones directas de componentes), priorizando la practicidad y evitando dependencias o ejecuciones de comandos prescindibles.
