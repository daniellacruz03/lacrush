# lacrush engineering

Plataforma oficial de desarrollo web e ingeniería de productos digitales de **lacrush engineering**.

## 🚀 Tecnologías
- **Astro 4**
- **React**
- **TypeScript**
- **CSS3 / Vanilla Design System (Apple Aesthetic)**

## 🛠️ Comandos
- `npm run dev` - Inicia el servidor de desarrollo local
- `npm run build` - Compila el proyecto para producción
